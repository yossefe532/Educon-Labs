# نظام حجز قاعات المدرسين

نظام كامل لإدارة حجز قاعات التدريس:
- جدول أسبوعي تفاعلي لكل الأيام والساعات
- إضافة موعد لمدرس (حجز ليوم واحد أو تعاقد دوري أسبوعي حتى نهاية التعاقد)
- لوحة تحكم (القاعات والأسعار والمدرسون والطلبات والإعدادات)
- شاشة عرض متحركة (Motion Graphics) تعمل على شاشة ثابتة بملء الشاشة
- رابط حجز خارجي يرسله المدرس طلبًا ويوافق عليه المسؤول عبر واتساب
- كشف تعارض تلقائي بين المواعيد

## التشغيل محليًا (للتجربة على الجهاز)

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`

- لوحة التحكم: `http://localhost:3000/admin` — كلمة المرور الافتراضية: `admin123`
- شاشة العرض: `http://localhost:3000/display` — اضغط F11 لملء الشاشة
- رابط الحجز: `http://localhost:3000/booking`

بدون إعداد أي سيرفر، البيانات تُحفظ محليًا في ملف `data/db.json`.

## الرفع على Vercel (مجاني)

1. ارفع المجلد على GitHub ثم استورده في Vercel (أو استخدم Vercel CLI).
2. من لوحة Vercel: **Storage → Create Database → Vercel KV** (الخطة المجانية تكفي).
3. اختر المشروع واربط قاعدة البيانات (Vercel سيضيف متغيرات البيئة تلقائيًا: `VERCEL_KV_REST_API_URL` و `VERCEL_KV_REST_API_TOKEN`).
4. أعد النشر. بعدها سيعمل النظام أونلاين والبيانات محفوظة في السحابة.

> لو رفعت النظام على Vercel بدون ربط Vercel KV، ستكون البيانات فارغة في كل دالة — لذلك ربط قاعدة البيانات ضروري.

## بعد الرفع

- غيّر كلمة المرور من «الإعدادات» في لوحة التحكم.
- أضف القاعات وأسعار الساعة من تبويب «القاعات والأسعار».
- انسخ روابط النظام من «الإعدادات → روابط النظام»:
  - ضع **رابط الحجز** في المنشورات وأرسله للمدرسين.
  - افتح **شاشة العرض** على الشاشة الثابتة في الواجهة بملء الشاشة.
- عند وصول طلب حجز من الخارج، يظهر في تبويب «الطلبات» — اضغط «اعتماد» ثم «واتساب» للتواصل مع المدرس مباشرة.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `VERCEL_KV_REST_API_URL` | رابط قاعدة بيانات Vercel KV (يُضاف تلقائيًا عند الربط) |
| `VERCEL_KV_REST_API_TOKEN` | رمز قاعدة البيانات |

## الهيكل

```
app/
  admin/       لوحة التحكم
  display/     شاشة العرض المتحركة
  booking/     رابط الحجز الخارجي
  api/         نقط النهاية (state, mutate, me)
lib/
  time.js      منطق الأيام والساعات والتعارضات
  storage.js   التخزين (Vercel KV أو ملف محلي)
  auth.js      جلسة تسجيل الدخول
```
